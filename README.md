# 昆山飘得华电子材料有限公司 - 产品客户管理系统

这是一个现代化、响应式且完全 Docker 化的客户管理系统仪表盘。
界面采用高端的毛玻璃拟态风格 (Glassmorphism) 设计，包含交互式数据看板和客户管理功能。

## 项目结构

- **纯前端 (Frontend-Only)**: 无需后端服务器支持，开箱即用。
- **技术栈**: HTML5, 原生 CSS3 (Glassmorphism), JavaScript (ES6+), Nginx, Docker。

## 如何运行

1.  在项目根目录下打开终端/命令行。
2.  运行以下命令：

    ```bash
    docker compose up
    ```

3.  等待容器构建并启动完成。

## 服务访问

-   **系统首页**: [http://localhost:3000](http://localhost:3000)

## 功能验证步骤

1.  **访问系统**: 在浏览器中打开 [http://localhost:3000](http://localhost:3000)。
2.  **数据看板**:
    -   确认页面加载时有平滑的进入动画。
    -   查看顶部关键指标 (KPI) 的数字滚动效果。
    -   确认图表 (Chart.js) 正常渲染销售趋势和客户分布。
3.  **客户管理**:
    -   点击侧边栏的 **"客户管理"** 菜单。
    -   **新增**: 点击 **"新增客户"** 按钮，在弹窗中填写信息并点击保存。系统应弹出 "成功" 提示，且列表中会出现新数据。
    -   **编辑**: 点击列表右侧的 **"编辑"** 图标，修改信息并保存。
    -   **删除**: 点击列表右侧的 **"删除"** 图标，**确认会弹出自定义确认框** (非原生弹窗)，点击确认后移除数据。
    -   **搜索**: 在上方搜索框输入客户名称（如"张伟"），列表应实时过滤。
4.  **交互体验**:
    -   **分页**: 点击底部的分页按钮，会显示 "演示功能" 的 Toast 提示。
    -   **个人中心**: 点击侧边栏底部的用户头像，会显示相应提示。
5.  **移动端适配**:
    -   将浏览器宽度缩小至手机尺寸 (或使用开发者工具移动端模式)。
    -   侧边栏应自动隐藏。
    -   点击顶部导航栏左侧出现的 **"汉堡菜单"** 按钮，侧边栏应滑出。
    -   点击遮罩层或菜单项，侧边栏应收起。

## 项目亮点

-   **UI 设计**: 采用深色科技风与磨砂玻璃质感，视觉层次丰富。
-   **零依赖**: 纯原生实现业务逻辑，无构建工具 (Webpack/Vite) 复杂度，修改代码即时生效。
-   **国内优化**: 静态资源 CDN 已替换为 BootCDN，确保国内访问速度。
